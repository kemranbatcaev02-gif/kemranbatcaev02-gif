В инженерной практике уделяю ключевое внимание отказоустойчивости, вычислительной эффективности и чистой масштабируемой архитектуре. - 💻 **Основной стек:** Go, Rust, React, Svelte, Flutter, Python (FastAPI), C++.
- 🛡️ **Сфера интересов:** Сетевые протоколы, сквозное E2E-шифрование, терминальные интерфейсы (TUI) и оптимизация производительности.
- 🐧 **Инфраструктура:** Развертывание и администрирование Linux-серверов (Docker, Nginx, Caddy, systemd).

## 🚀 Проекты

### 1. ⚡ [PocketFlow](https://github.com/kemranbatcaev02-gif/pocketflow)
> **Терминальный трекер личных финансов на Go.**
- **Стек:** `Go 1.22+`, `Bubble Tea`, `Lipgloss`, `SQLite`, `Bubbles`.
- **Что внутри:** Управление транзакциями (доходы и расходы), лимиты бюджетов по категориям, интерактивный фильтр и поиск, экспорт отчетов в CSV и JSON, хранение данных в локальной SQLite.

### 2. 🛡️ [ViperLog](https://github.com/kemranbatcaev02-gif/viperlog)
> **Высокопроизводительный инструмент для потокового анализа и мониторинга логов на Rust.**
- **Стек:** `Rust`, `Tokio`, `Clap v4`, `Regex`, `Chrono`, `Serde`.
- **Что внутри:** Потоковая обработка Nginx/Apache/JSON логов, фильтрация по regex и уровням логирования, автоматическое маскирование персональных данных (токены, пароли, IP) и подсчет метрик (RPM, топ IP-адресов, распределение кодов ответа).

### 3. 💬 [Connecto — Private Messenger](https://github.com/kemranbatcaev02-gif/Connecto---private-messenger)
> **Кроссплатформенный мессенджер с акцентом на приватность и сквозное шифрование.**
- **Стек:** `Flutter (Dart)`, `FastAPI (Python)`, `WebSockets`, `WebRTC`, `Curve25519 + AES-256-GCM`, `SQLite`.
- **Что внутри:** E2E-шифрование сообщений, самоуничтожающиеся чаты, P2P аудио/видеозвонки через WebRTC и кастомный Glassmorphism UI.
- **Ссылки:** [📢 Telegram-канал проекта](https://t.me/connecto_official) • [🌐 Web-версия (Beta)](https://connectomes.duckdns.org)

### 4. 🐳 [DockDash (Wharf)](https://github.com/kemranbatcaev02-gif/dockdash)
> **Интерактивный терминальный дашборд (TUI) для управления контейнерами Docker на Go.**
- **Стек:** `Go`, `Bubble Tea`, `Docker Engine SDK`, `Lipgloss`.
- **Что внутри:** Мониторинг запущенных контейнеров, живой стриминг логов, графики потребления CPU и RAM, горячие клавиши для быстрого старта/остановки и встроенный демо-режим.

### 5. 🌸 Bloom — Social Network
> **Тематическая социальная сеть с упором на авторский контент и безопасность.**
- **Статус:** В активной разработке, концепция и архитектура готовятся к защите на проектном акселераторе **Leader-ID**.

### 6. 🕹️ [Tetris Deluxe](https://github.com/kemranbatcaev02-gif/tetris-deluxe)
> **Классическая аркадная игра на C++17 и библиотеке SFML 3.**
- **Стек:** `C++17`, `SFML 3.0`, `CMake`.
- **Что внутри:** Кастомный рендеринг, система прокачки уровней, физика частиц и сохранение рекордов в бинарный профиль.

### 7. 💻 [SystemMonitor](https://github.com/kemranbatcaev02-gif/SystemMonitor)
> **Десктопный монитор ресурсов системы на Python и Qt (PySide6).**
- **Стек:** `Python`, `PySide6 (Qt6)`, `psutil`.
- **Что внутри:** Векторные круговые датчики загрузки процессора и памяти, сглаженные графики сетевой активности и список активных процессов.

### 8. 🎨 [Git Heatmap Painter](https://github.com/kemranbatcaev02-gif/git-heatmap-painter)
> **Консольный инструмент для рисования пиксель-арта на графике активности GitHub.**
- **Стек:** `Python 3.8+` (Zero Dependencies), `Subprocess`, `ANSI Colors`.
- **Что внутри:** Пресеты (Invader, Cat, Heart, Ghost, Skull), генератор 7-строчного текста, предпросмотр в терминале и мгновенный буст активности.

### 9. 👾 [Commit-Gotchi](https://github.com/kemranbatcaev02-gif/commit-gotchi)
> **Терминальный виртуальный питомец-тамагочи, питающийся коммитами в Git.**
- **Стек:** `Python 3.8+` (Zero Dependencies), Git CLI integration, state persistence.
- **Что внутри:** 4 вида питомцев (Neko, Rex, Ferris, Shiba), шкалы сытости и настроения, режим бога (10x Dev) при 20+ коммитах и поддержка Git post-commit хуков.
